ПЛАН ВЫЧИТКИ ОРИГИНАЛА

Для того чтобы выполнить вычитку оригинала, необходимо применить нижеприведенные методы и способы корректорского чтения.

Методы чтения оригинала:

Ознакомительное чтение — знакомство с содержанием и элементами литературного произведения.

Смысловое чтение — основное чтение, которое помогает выявить в оригинале ошибки.

Чтение с установкой на побуквенную (познаковую) проверку текста — фиксирующее чтение, при котором идёт более детальная вычитка.

Способы чтения оригинала:

Сквозное смысловое чтение — беглое, контроль смыслового и стилистического единства текста.

Вертикальный просмотр — просмотр, при котором из всей корректуры выделяется отдельный элемент.
